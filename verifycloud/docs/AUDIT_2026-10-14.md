## What was verified for the first time

- CI on GitHub-hosted runners is green: run 38740646066 (commit 8d8bc89),
  jobs `test` (typecheck, lint, build, full vitest suite with MinIO and the
  Docker sandbox) and `images-and-e2e` (Compose stack + Playwright browser
  E2E). The earlier run 38705474615 had 155 passed, 2 failed, 1 skipped.
- MinIO (RELEASE.2025-04-22, commit 0d7408fc): storage tests and persistence
  across a MinIO restart.
- `docker compose up` with `postgres:16.10`, MinIO and the built images: demo
  regression gives the designed result; 46 artifacts byte-identical after
  restarting MinIO, PostgreSQL and the API. The browser E2E ran against the
  Compose stack on GitHub CI (not in this container).
- gVisor `runsc` release-20260928.0 as the sandbox runtime: 5/6 selected
  sandbox tests and 2/2 adversarial tests pass.
- Lease fencing with separate worker processes: SIGKILL, SIGSTOP past the
  lease (late writes refused, recorded result unchanged), ±2 h skew and a
  40-day clock step. Note: the clock-step test also passed on the pre-fix
  code (the step happened before any task ran), so F4's failing-first
  evidence is the server-level test.
- Adversarial RTL: host-file `$fopen` and `` `include ``, writes outside the
  run directory, DPI-C imports bound to libc (`system`, `unshare`, `setuid`),
  elaboration-time infinite loop, oversized design.
